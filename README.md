Coursework and capstone projects from the **Data Science, Analytics & Artificial Intelligence in Python** postgraduate program at PUC-Rio (Pontifícia Universidade Católica do Rio de Janeiro). This repository is organized by subject area, with the five capstone ("MVP") projects as the main portfolio pieces.

> Course lecture slides and other copyrighted third-party material are intentionally excluded from this repository — only original work (notebooks, code, analysis, and reports) is versioned here.

## Capstone projects (MVPs)

| Project | Area | Summary |
|---|---|---|
| [Global CO₂ Emissions & Absorption](ciencia-de-dados-e-analytics/mvp-engenharia-de-dados) | Data Engineering | End-to-end ETL pipeline integrating public climate datasets (Carbon Monitor, NASA, UN, World Bank...) to analyze global CO₂ trends. |
| [Blood Donor Registry Analysis](ciencia-de-dados-e-analytics/mvp-analise-de-dados-e-boas-praticas) | Data Analysis & Best Practices | Hypothesis-driven exploratory analysis of a blood donor registry: demographics, blood type restrictions, and donation behavior. |
| [Room Image Classifier](ciencia-de-dados-e-analytics/mvp-machine-learning-e-analytics) | Machine Learning & Analytics | CNN-based computer vision model classifying house interior photos into 5 room types. |
| [EasyBola — Product Backlog](engenharia-de-software/mvp-gestao-agil-projetos-produtos) | Agile Project & Product Management | Lean Inception, MVP Canvas, and product/sprint backlog for a pickup-soccer scheduling app. |
| [Diabetes Prediction API](engenharia-de-software/mvp-qualidade-seguranca-sistemas-inteligentes) | Quality & Security of Intelligent Systems | Full-stack app: Flask REST API serving a diabetes-risk ML model, with automated tests and a web front-end. |

## Repository structure

- **[`ciencia-de-dados-e-analytics/`](ciencia-de-dados-e-analytics)** — Data Science & Analytics track: databases, data warehouse/data lake, exploratory data analysis, data visualization, machine learning, advanced analytics (deep learning/CV/NLP), OOP, and the first 3 MVPs above.
- **[`engenharia-de-software/`](engenharia-de-software)** — Software Engineering track: databases, OOP, engineering of intelligent software systems, web development, and the remaining 2 MVPs above.

Each subfolder has its own `README.md` describing its contents and tech stack.

## Tech stack

Python, Pandas, NumPy, scikit-learn, TensorFlow/Keras, Flask, SQL/SQLite, Matplotlib/Seaborn, HTML/CSS/JavaScript.
