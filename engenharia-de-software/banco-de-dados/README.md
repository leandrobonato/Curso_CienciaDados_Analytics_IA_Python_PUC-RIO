# Databases

Coursework: relational database exercises for the Software Engineering track — schema design, DDL/DML/SELECT/sub-query practice, and a sample SQLite database ("EAD" — a distance-learning platform schema) used across the exercises.

## Contents

- `BD_Aula1.ipynb` / `BD_Aula2.ipynb` / `BD_Aula3.ipynb` — per-lesson exercises.
- `Exemplos_DDL.sql`, `Exemplos_DML.sql`, `Exemplos_SELECT_1.sql`, `Exemplos_SubSELECT_2.sql`, `Exemplos_Restricoes.sql`, `Exemplos_CreateObj.sql` — SQL examples by topic.
- `Lógico_EAD.sql`, `exportar_EAD.sql`, `eadv1.db`, `eadv2.db` — sample "EAD" schema and SQLite database versions.

## Tech stack

SQL, SQLite.
