# Exploratory Data Analysis & Pre-Processing

Coursework: exploratory data analysis and pre-processing techniques (missing values, outliers, normalization, feature engineering), including an auto-generated profiling report on a diabetes dataset.

## Contents

- `AEPD_*.ipynb` — exercises per lesson (importing datasets, exploratory analysis).
- [`Análise_Exploratória_e_Pré_Processamento_de_Dados.ipynb`](Análise_Exploratória_e_Pré_Processamento_de_Dados.ipynb) — consolidated notebook.
- [`report-diabets.html`](report-diabets.html) — automated data-profiling report.

## Tech stack

Python, Pandas, ydata-profiling/pandas-profiling.
